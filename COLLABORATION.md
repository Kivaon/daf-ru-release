Один активный checkout (текущая версия): `Codex/2026-10-11/daf-ru-users-kivaonmac-documents-codex/work/daf-ru-release`. Не создавать новых копий; `work/daf-ru` (Kivaon/daf-ru) — это бэкап со старыми версиями, не рабочая копия.

## Правила

1. **Один пишет — второй не правит.** Перед работой прочитать `HANDOFF.md` (внизу — последняя запись) и `git log -5`; в начале и в конце сессии `git status` должен быть понятен. Не работать одновременно двумя агентами.
2. **Каждая сессия заканчивается так:** тесты (`npm test`), `npm run typecheck`, при значимых правках `npm run build`, коммит, и **короткая запись в конец `HANDOFF.md`** (дата, кто, что сделано, коммит, что не проверено, следующий шаг).
3. **Разделение ролей:**
   - Claude Code — код, тесты, документация, разведка и подготовка (всё, что не требует доступа к Sites).
   - ChatGPT/Codex — всё, что требует Sites: `get_site`, credential, `site-workflow` (open/save/deploy), выгрузка боевой БД.
   Публикация только после подтверждения пользователя. Footer и номер версии обновляет тот, кто публикует; следующий номер сверять с Sites.
4. **Не трогать:** существующие переводы и ручные правки, JSON recovery, публичный доступ, «О проекте» ради handoff, секреты. Токены и credential в файлы, логи и коммиты не писать.
5. **Данные пользователей** (выгрузки БД) хранить вне репозитория.
6. Если один агент упёрся в ограничение (разрешения, доступ), он **останавливается, записывает причину в HANDOFF.md и не обходит защиту**.
