# DAF-RU

Существующее приложение для предварительной подготовки к изучению Гемары на русском языке.

Сначала прочитайте `PROJECT.md`, `SPEC.md`, `HANDOFF.md`. Не создавайте проект заново.

## Локальный запуск

Node.js >=22.13, установленный npm и зависимости из package-lock.json.

```sh
npm ci
npm run db:local
npm run dev
```

`db:local` применяет существующие SQL-миграции только к локальной D1 в `.wrangler/state`. Повторный запуск не пересоздаёт таблицы. Это не загрузка production-данных. Локальная конфигурация `.openai/local-db.json` служит миграциям и генерации типов; Vinext использует `vite.config.ts`.

Откройте адрес, напечатанный сервером (обычно http://localhost:3000). Для оригиналов нужен доступ к Sefaria и Shas.org. Гостевой просмотр работает без входа; реальная авторизация и доверенные заголовки пользователя предоставляются Sites.

## Проверки

```sh
npm test
npm run typecheck
npm run build
```

Тесты проверяют печать и привязку статей, а не прежнюю заглушку стартового шаблона. Проверка типов исключает временные рабочие каталоги. После изменения bindings обновите типы:

```sh
WRANGLER_LOG_PATH=.wrangler/logs npx wrangler types cloudflare-env.d.ts --config .openai/local-db.json
```

Для публикации используйте workflow существующего Sites-проекта из `.openai/hosting.json`. Перед публикацией проверьте параллельные изменения в этой общей рабочей папке. Не подменяйте опубликованную базу локальной.
